# Bank Loan Performance Analysis Dashboard

## Project Overview
This is a learning project created using Microsoft Power BI to analyze bank loan data and visualize key performance indicators through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Dashboard Features
- Loan application analysis
- Total funded amount and amount received
- Average interest rate and debt-to-income (DTI) ratio
- Good loan vs. bad loan analysis
- Summary and Overview report pages

## Learning Outcomes
- Creating interactive Power BI dashboards
- Understanding KPIs and financial data
- Practicing data visualization and analysis
